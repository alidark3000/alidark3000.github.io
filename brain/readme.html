1. Architecture & Local-First Design

Ali Brain is an autonomous, serverless personal knowledge management system that runs entirely in your browser using standard web technologies. It stores your complete database directly on your local file system, providing instant load times, complete data ownership, and offline capability without relying on centralized databases or servers.

  • Single JSON Database File: All entries, generated prompt questions, prompt reflection answers, taxonomies, assistant chat histories, and deletion tombstones are stored in a single JSON file on your computer.
  • IndexedDB Persistence: File handles are retained via idb-keyval so you can resume your active workspace upon reload without picking the file again. An automatic backup snapshot is also written to IndexedDB on every save.
  • Privacy by Default: Zero telemetry, zero analytics, zero external database servers. Communication occurs solely between your browser and the Google Gemini API when using AI features.

2. Multi-Computer Non-Destructive Sync

The synchronization engine ensures safe, concurrent multi-device usage over folder-sync tools like Dropbox, Google Drive, iCloud, or Syncthing. Rather than blindly overwriting entire files, Brain analyzes granular note timestamps to perform non-destructive merges, preserve simultaneous edits, and prevent accidental data loss.

Dirty-State Guard

Computers left open in the background never blind-save stale memory snapshots. If no local changes have been made on that device, auto-save timers will not touch or overwrite the file on disk.

Read-Before-Write 3-Way Merge

Before saving local modifications, Brain inspects the file on disk. If another computer wrote to the file, Brain reads and merges entries non-destructively using individual updatedAt timestamps.

Conflict Preservation

If the exact same note was edited concurrently on two computers, the newer timestamp becomes primary, and the older edit is cloned non-destructively as a [Conflict Copy] note so nothing is lost.

Deletion Tombstones

Deleted notes record a timestamped tombstone in the database (tombstones: { [id]: timestamp }). This prevents deleted notes from being resurrected by other computers. Tombstones older than 60 days are pruned automatically.

Live Focus & Background Pulling: Switching to the Brain tab (or while idle) automatically polls the disk file. When remote changes are detected, the workspace reloads and updates the view seamlessly.

3. Entry Types & Taxonomy Solo Filtering

The taxonomy and organization system categorizes your knowledge base into distinct functional entry types alongside multi-dimensional tags, categories, and projects. It provides instant filtering controls, drag-and-drop organization, and solo views to isolate specific subsets of notes rapidly.

Notes • Manual User Thoughts Prompts • AI Theme Reflection Notes Media • Videos & Audio (YouTube/Vimeo) Web • Scraped Web Pages, Articles & PDFs AI Chat • Archived AI Conversations
Core Filtering & Taxonomy Capabilities:
• Type Toggle: Click any entry type badge to toggle that type on or off in the list. Note that AI Chat is hidden by default to keep your note list uncluttered.
• Solo Filtering: Shift + Click any type to solo it — hiding all other types in a single click. Shift-clicking the active solo type again restores all default types.
• Multi-Dimensional Taxonomy: Filter notes by Projects, Categories, and Tags. Drag notes directly onto taxonomy items in the sidebar to assign them instantly.
• Taxonomy Management: Hover over any project, category, or tag in the sidebar to reveal a delete button that removes the taxonomy across all notes in the database.
• Pinning: Pin essential notes to keep them anchored at the top of the list for fast reference.
• Fast Search & Clear: Real-time text search filters across titles and note contents. An inline clear button and Escape shortcut instantly reset your query.
• Taxonomy & Entry-Type Separation: AI taxonomy generation and auto-tagging strictly separate structural document formats (notes, media, web, prompts, ai chat) from domain topics to keep your taxonomy clean.

4. Inline Editing & Field Generators

The document editor delivers a seamless, in-place writing and curation workflow. Every individual component of a note can be edited directly without opening separate modal forms, while dedicated AI action triggers allow you to selectively regenerate or refine specific fields on demand.

Double-Click Inline Editing

Double-click any field — Title, Executive Summary, Answer Summary, or Takeaways — to edit it directly in place. Edits commit automatically on blur or Enter.

Targeted Field Generators & Auto-Metadata

Independent refresh buttons beside each section trigger Gemini AI to re-extract or suggest content for only that specific field (Title, Taxonomy, Summary, or Key Takeaways) without affecting the rest of the document. When a user finishes editing a note (via Done, clicking outside, or exiting Focus Mode), the system automatically synthesizes a descriptive title (if untitled), a substantive executive summary, and contextual domain taxonomies (projects, categories, and tags) in the background, while key takeaways are generated on-demand when the user clicks the refresh action.

Unified Instruction Registry (Single Source of Truth): Both targeted individual field generators and the combined initial auto-generation pipeline share a canonical, DRY instruction registry (METADATA_FIELD_SPECS). Dynamic prompt construction, schema definitions, token budgets (300 for titles, 600 for taxonomies, 800 for summaries/takeaways, and 1000 for combined synthesis), and sanitizers are maintained in one place, ensuring 100% prompt consistency and zero behavioral drift between single-field and multi-field synthesis.

In-Place Taxonomy Editor

Clicking the taxonomy badges in the note header opens an inline manager to add new tags, remove existing tags, or trigger AI auto-tagging.

Distraction-Free Focus Mode

Double-clicking note content or clicking Edit opens an inline textarea editor with a visible Focus Mode link. Activating Focus Mode launches a centered distraction-free writing window. Exiting Focus Mode (via Esc, backdrop click, or close button) immediately finishes editing, saves all changes, and returns to the rendered Markdown reader view.

Workspace State Persistence: The open/collapsed states of sidebars and panels are persisted into your workspace file and restored automatically across sessions.

5. Content Ingestion & Media Scrubbing

The ingestion pipeline transforms raw web links, multimedia URLs, and pasted text into clean, structured knowledge entries. Ingested content is automatically sanitized, formatted into Markdown, and enriched with AI-generated metadata.

  • Web Article Scraping: Strips navigation bars, advertisements, cookie notices, and scripts using turndown to capture clean article text and formatting.
  • Media Embedding: Automatically recognizes YouTube and Vimeo links to embed a responsive media player alongside synchronized note-taking capabilities.
  • Direct Substance Metadata Extraction: When a user finishes editing a note, Gemini AI automatically synthesizes a concise title (if untitled), a substantive executive summary (2–3 informative sentences articulating context, core arguments, and takeaways without throat-clearing preambles), and contextual domain taxonomies (projects, categories, and tags). Key takeaways are generated on-demand when explicitly triggered via their respective refresh button.

6. Gemini AI Synthesis & Theme Prompt Generator

The Theme Prompt Generator acts as an autonomous intellectual sparring partner. By analyzing themes, contradictions, and loose ends across your knowledge base, it generates thought-provoking reflection questions that prompt you to write new notes and deepen your understanding.

Synthesis Hierarchy & Generation Logic:
1. Primary Topics (Highest Weight): Manual notes receive the highest priority, grounding questions in your original ideas and personal reflections.
2. Secondary Topics: Previous prompt responses explore how your perspective has evolved over time.
3. Supporting Context: Ingested external materials (Web, Media, PDF) provide background references without becoming the sole subject of prompts.
Temporal Weighting: Evaluates your complete knowledge base across all time, giving ~65% priority to notes created or modified in the last 4 months.
Prompt Generation Settings & Customization: Located directly beside the "Generate Prompt" button, a gear icon opens configurable parameters for synthesis:
  • Creativity Level (Temperature): A slider ranging from 0.0 (precise and deterministic) to 1.0 (exploratory and divergent), defaulting to 0.7. Strictly governs temperature end-to-end across Round 1 note scouting, Round 2 deep reasoning synthesis, and repair loops.
  • Gemini Model Assignment: A dropdown allowing you to override the model used for synthesis or inherit the workspace default (taskModels.prompts || gemini-flash-lite-latest).
  • Number of Recent Notes: A slider adjusting the candidate pool size from 5 to 60 (default: 35). Strictly selects your freshest notes in chronological order (newest first), ensuring your most recent manual thoughts, outlines, and reflections are prioritized for synthesis.
  • Reset to Defaults: A one-click master button restoring creativity to 0.7, inheriting the workspace prompt model, and resetting the candidate note limit to 35.
Scoped Context & Candidate Selection: Whatever entries are currently shown in the entry list view (filtered by type, project/category/tag taxonomy, or search query) form the candidate pool for prompt generation. The candidate pool sorts all summarized visible notes chronologically (newest first) and selects up to the configured limit (default: 35 entries):
  • Chronological Recency Prioritization: Populates candidate slots starting with the freshest manual notes and prompt reflections created or modified in the recent 4-month window, followed by recent external context notes.
  • Historical Top-Up: If fewer recent notes exist than the configured target, remaining slots are filled with earlier historical notes in chronological order.
If list filters are active, prompt synthesis isolates itself strictly to those visible notes, and notes created from the prompt inherit active taxonomies. AI Chat archive entries, the starter welcome note, and any notes lacking both an executive summary and key takeaways are strictly excluded from the prompt candidate pool under all conditions. When only the default-hidden AI Chat type is deselected, the "Generate Prompt" button cleanly displays its standard label without listing type filters, treating all content types as active.
Minimum Entry Requirement: The "Generate Prompt" button requires at least 2 summarized non-chat notes (possessing an executive summary or key takeaways) visible in the list view; when fewer than 2 summarized notes exist, the button is hidden to ensure only processed notes are synthesized.
Two-Pass Synthesis & Complete Unabridged Notes: Theme prompt generation operates via an efficient two-round architecture. In Round 1, an efficient scouting pass scans candidate note profiles (titles, timestamps, roles, summaries, and key takeaways) to identify the core conceptual contradiction, paradox, or collision between 2–3 notes. In Round 2, the engine injects the 100% complete, unabridged text of those chosen notes into the deep reasoning prompt—eliminating previous 350-character snippets and ensuring the AI reasons over full contexts without misinterpreting text boundaries as thoughts trailing off mid-sentence.
Inline Note References: Prompts automatically embed bi-directional references ([[kb-ref:ENTRY_ID]]) to source notes, allowing immediate preview and navigation.
Non-Repetition & Candidate Novelty Engine: Retains a history of previously generated prompts and referenced note IDs in storedPrompts. In Round 1, candidate notes are dynamically partitioned so unexamined notes appear at the top of the candidate index, while previously paired notes are deprioritized. Explicit novelty constraints instruct the model to explore fresh, unexamined contradictions rather than repeatedly retreading the same note pairs.
Organic Issue-Driven Inquiry Engine (No Formulaic Question Stems): Prompt synthesis strictly bans formulaic, repetitive question stems (such as "How do you explain...", "Can you explain...", or "How do you reconcile...") as well as all action-oriented, advice-seeking, or life-coaching questions (e.g. "What is one tangible action you can anchor yourself in today?", "What is one small step / action / shift...", "How might you..."). Instead, questions are constructed organically and directly out of the specific tension, contradiction, loose end, or juxtaposition identified across the notes (e.g., examining which force governs a collision, where a premise breaks down under pressure, or what allows opposing standards to coexist). Features runtime pattern detection, analytical repair loops, and deterministic fallback rephrasing to guarantee deep, organic intellectual inquiry.
Mandatory JSON Schema Contracts & 8,192 Token Reasoning Budget: Both Round 1 scouting and Round 2 synthesis enforce explicit responseSchema contracts with required title and content fields, supported by an expanded 8,192-token ceiling to prevent reasoning models (like gemini-pro-latest and gemini-2.5-pro) from truncating questions mid-sentence when thinking tokens consume generation limits. Supported by multi-key regex extraction, thinking token isolation, and automated fallback safety nets, the prompt engine guarantees the prompt card is never presented empty or syntactically broken.

7. Unified AI Assistant & Chat Modes

The integrated AI Assistant provides conversational intelligence directly alongside your notes. It can switch dynamically between deep inspection of your currently open document and multi-pass synthesis across your entire library of notes.

  • Current Entry Mode: Injects the active note's full text, summary, takeaways, and source link alongside the summaries and takeaways of up to 10 same-category/project notes. The conversation is hosted inside the right collapsible drawer, bound to the open document with quick prompt chips.
  • Search Grounding Disabled: Google Search grounding tools are disabled across all assistant modes (single-note, workspace, and whole brain) to eliminate massive token retrieval overhead and keep conversations grounded exclusively in your notes.
  • Full-Width Whole Brain AI View: Uses two-pass retrieval that scans one-line note summaries across the library to identify relevant entries, then injects the complete text of the top 5 matching notes for synthesis. The main document view is fully replaced with an expansive, dedicated AI Chat interface featuring pinned message history, real-time citation synthesis, and a bottom input bar.
  • Immediate Placeholder Creation: Starting a new Whole Brain chat immediately creates a dedicated AI Chat placeholder entry (purple) in the library so every conversation exists as its own persistent entity from the very first moment.
  • Non-Destructive Archival & Natural Continuation: Every message exchange is stored non-destructively directly on the active AI Chat entry. When you select an archived AI chat from the notes list, its entire conversational transcript and message history are automatically repopulated into the full-width AI view, allowing you to continue the conversation naturally while preserving session integrity and auto-updating summaries.
  • Initial Note Selection on Load: Because AI Chat entries have visibility turned off by default in the list view, opening the application automatically selects the most recent non-AI Chat note (or top visible entry according to active type filters) so you are immediately presented with an active, visible document.
  • Direct Content Insertion: One-click insertion transfers assistant answers or synthesized outlines straight into your active note editor, syncing in-memory edit buffers so subsequent edits and auto-saving never overwrite or discard inserted content.
  • Automatic Empty Placeholder & Manual Note Cleanup: If a user creates a new blank manual note or a new Whole Brain AI chat and navigates away or clicks off without writing any content, the empty entry is automatically deleted and pruned from the library and navigation history to prevent abandoned blank records.
  • Auto-Focus on AI Chat Creation: Creating a new Whole Brain AI chat session or navigating to an AI chat entry automatically focuses the chat input field so you can begin typing immediately.
  • Strict Assistant Drawer Segregation: Whole Brain chat mode is completely isolated from Current Entry chat. When in Whole Brain chat, the top-right magic wand toggle button is cleanly removed from the DOM entirely, keyboard shortcuts (Cmd+J / Cmd+L / Ctrl+J) are ignored, and the assistant drawer is automatically collapsed so Current Entry chat can never be accessed during Whole Brain chat.
  • Clean Borderless Message Bubbles & Layout: All message entries across both the full-width Whole Brain conversation and the Current Entry assistant drawer are designed without borders, floating with clean contrast and subtle card shadows against the canvas. In Whole Brain mode, dividing lines below the header and above the message input bar are eliminated for a seamless document flow.
  • Concise & Conversational Response Rules: Across all assistant modes (Whole Brain and Current Entry), AI responses are governed by strict concise writing rules and a 50-word target limit unless longer answers are specifically requested or necessary, defaulting to short. Assistant models are calibrated with a focused temperature of 0.3. The assistant proceeds step-by-step, avoids spilling large amounts of text, uses the active voice, cuts unnecessary filler, prefers short words and plain English, keeps sentences declarative and focused (one idea per sentence), uses natural contractions, reserves emojis strictly for headers, and cites sources cleanly using [[kb-ref:ID]].
  • Keyboard Accessibility: Toggle the assistant drawer anytime with Cmd+J or Ctrl+J when viewing standard notes.

8. Backlinks & Decimal Numeric IDs

Ali Brain implements a lightweight, bi-directional referencing and linking network. You can connect ideas across different documents seamlessly without relying on proprietary database graph structures or fragile absolute paths.

  • Wiki Shortcodes: Using [[kb-ref:ENTRY_ID]] establishes an interactive link. Hovering over the reference renders an instant summary popover, while clicking navigates directly to the referenced note.
  • Drag to Reference: Drag any note card from the sidebar list and drop it into the Markdown editor to automatically insert a formatted reference link.
  • Chronological Decimal IDs: Notes use stable decimal identifiers (e.g. #1, #2, #2.1), permitting chronological insertions into intermediate timeline gaps while maintaining stable referencing.

9. Settings & Workspace Management

Workspace settings give you comprehensive control over AI configuration, model assignments, API key rotation, and multi-file merges. All settings are stored locally within your browser and knowledge base file.

  • API Key Management: Store and rotate multiple Google Gemini API keys to distribute usage across quotas.
  • Task-Specific Model Assignment: Assign distinct Gemini models optimized for specific task categories:
    • Metadata & Summaries: High-speed models (e.g. gemini-flash-lite-latest) for fast titles, takeaways, and auto-tagging.
    • Theme Prompts: High-reasoning models for synthesizing loose ends and generating reflection questions.
    • AI Assistant Copilot: Interactive models for contextual chatting and knowledge-base synthesis.
  • Live Model Discovery: Dynamically fetch available models directly from Google AI Studio to select the latest versions and experimental releases.
  • Workspace Merging: Merge secondary JSON knowledge bases into your active workspace with automatic duplicate handling and conflict resolution.
